<img>

La etiqueta <img> sirve para mostrar una imagen en una página web.

<input>

La etiqueta <input> sirve para crear campos donde el usuario puede introducir información.

<link>

La etiqueta <link> sirve para enlazar recursos externos con el documento HTML, como una hoja de estilos CSS.

<meta>

La etiqueta <meta> proporciona información sobre el documento HTML. El atributo charset indica la codificación de caracteres, viewport adapta la página a diferentes dispositivos y description describe el contenido de la página.

<col>

La etiqueta <col> permite aplicar estilos o propiedades a una columna de una tabla. Se utiliza dentro de un elemento <colgroup>.

<embed>

La etiqueta <embed> sirve para incrustar contenido externo, como un archivo multimedia o un documento, dentro de una página web.

<param>

La etiqueta <param> se utilizaba para definir parámetros de elementos incrustados. Actualmente está obsoleta en HTML5.

Ejemplo:

<param name="autoplay" value="true">

<source>

La etiqueta <source> sirve para especificar diferentes recursos multimedia para elementos como <audio> y <video>.

<wbr>

La etiqueta <wbr> indica un posible punto de salto de línea dentro de una palabra o texto largo.

Ejemplo de texto muy largo: supercalifragilisticoespialidoso
